# Clarivate

> Clarivate is a global information services company providing data, insights and analytics
> across academia and government, life sciences and healthcare, and intellectual property. Its
> APIs are published on one developer portal at developer.clarivate.com and served through one
> gateway at api.clarivate.com. Every API is credential-gated: an API key in the X-ApiKey header
> (or OAuth 2.0 client credentials), issued per registered application, and for all but one plan
> entitled from the institution's product subscription.

## How to call it

- Base host: `https://api.clarivate.com` (InCites is `https://incites-api.clarivate.com`, WoS Lite is `https://wos-api.clarivate.com`).
- Auth: `curl -H 'X-ApiKey: <key>' https://api.clarivate.com/<api>/<endpoint>`.
- OAuth 2.0 client credentials: `POST https://api.clarivate.com/auth/{auth-method}/api/{api}/token`, returns a bearer token with `expires_in: 3600`.
- Pagination (Web of Science Starter / Journals / Researcher): `page` and `limit` (0-50, default 10); the response carries `metadata.total`, `metadata.page`, `metadata.limit`.
- Errors: `{"error": {"status", "title", "details"}}`; 401 returns `{"error_description", "error"}`; gateway rejections return `{"message", "request_id"}`. Not RFC 9457.
- Throttles are published per plan (1-5 requests/second) but NO rate-limit response header, 429 body or Retry-After is documented.
- There is no sandbox, no test mode, no idempotency key and no webhook or event surface anywhere in the estate.

## Standards this estate speaks

- **NISO SUSHI / COUNTER Release 5** — the Web of Science SUSHI API and the Cortellis Drug Discovery Intelligence SUSHI API implement the COUNTER R5 Code of Practice with the canonical report paths (`/status`, `/members`, `/reports`, `/reports/pr`, `/reports/pr_p1`, `/reports/dr`, `/reports/dr_d1`, `/reports/dr_d2`). A COUNTER 5.1 status endpoint is served unauthenticated at `https://api.clarivate.com/api/counter/r51/status`.
- **ORCID** — a first-class search field of the Researcher API (`ORCID=0000-0000-000-0000`), joinable to Clarivate's ResearcherID.
- **DOI / ISSN / eISSN / ISBN / PMID** — declared identifier fields and search field tags, not free text.

## Deprecated and retired

- **EndNote REST API** — marked deprecated on the portal; no new subscriptions.
- **DI GraphQL API (`POST /derwent-graphql`)** — marked deprecated; superseded by the IP Data API.
- **Web of Science API Lite** — "replaced by the Starter API".
- **Web of Science Expanded (SOAP)** — sunset 2023-11-01 after scheduled brownouts and warning headers.
- **Links AMR** — sunset; the Starter API's `SUR` search tag and `detail=short` replace it.
